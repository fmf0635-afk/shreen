# BlueWave Swimming Club — Social PWA Final

- Instagram-style swimming feed, stories, suggestions and trends.
- Visitor accounts: name, email, mobile, password.
- Visitor likes, saves and comments.
- Admin-only management remains protected.
- Install App button with Android/Windows prompt and iPhone/iPad instructions.
- PWA manifest + service worker, GitHub Pages ready.

Demo social account data is stored in browser localStorage. A shared online database/authentication is required for real multi-device accounts.
