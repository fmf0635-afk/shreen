# BlueWave Swimming Club — Social PWA

Instagram-inspired swimming club website with:
- Admin-only swimmer/coach/payment/post management
- Visitor accounts (name, email, mobile, password)
- Visitor likes, saves, and comments
- Install App button / PWA
- iPhone/iPad Add to Home Screen instructions
- Android and Windows PWA installation
- Responsive social feed, stories, suggestions and trends
- GitHub Pages ready

Important: visitor accounts and social interactions in this demo use browser localStorage. For true multi-device accounts and shared posts/comments, connect a backend database/auth service.
