# BlueWave Swimming Club — GitHub Pages

1. Create a GitHub repository.
2. Upload all files in this folder to the repository root.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Open the generated HTTPS site.
6. On Android/Windows, use **Install App**.
7. On iPhone/iPad, open the site in Safari → Share → **Add to Home Screen**.

The site is designed to work as a PWA and includes a manifest, service worker, icons, iOS metadata, and offline caching.
